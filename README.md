## Description
Just a simple Rock, Paper, Scissors game I made in Python for Assignment 7. It asks for your name, lets you pick a move, and then has the computer randomly pick one to see who wins the round.

## Inputs
- Name (string)
- Choice (`rock`, `paper`, or `scissors`)
- Play again prompt (`yes` or `no`)

## Outputs
- Welcome message with your name
- What the computer chose
- If you won, lost, or tied
- Thanks for playing message at the end
